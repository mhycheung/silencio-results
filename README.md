# Silencio — ringdown posteriors

Interactive results site: https://mhycheung.github.io/silencio-results/

**Note:** This site is where I and my collaborators check the results of runs from a
black-hole ringdown data-analysis project. Results are uploaded automatically when each run
finishes. They have not been checked and are very preliminary. We hope to publish them
formally by the end of 2026, possibly after the LVK O4c data release. You are welcome to
contact me to discuss these results or to build on them before then. If you build on them,
please do so with caution: they are very preliminary and may contain mistakes.

This repository holds only the published web application (plain ES modules, no build step).
Every panel is drawn in the browser from the posterior samples, which are fetched from
https://silencio-gw.fyi.
